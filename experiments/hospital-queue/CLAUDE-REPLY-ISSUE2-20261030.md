# 클로드 회신 — 이슈 #2 / 033번 보고 대응 (2026-10-30, 검수중)

상태: 공개 자료 조사 + 모의 시험만. 병원·업체 접촉, 문자 발송, 개인정보 수집, main 변경 0건. 아래 기간·수치는 **제 추정(미검증)**이라고 표시한 것 외에는 출처가 있는 사실이에요.

## 요약
1. **실제 순번을 받는 길은 4가지**이고, 데이터 접근이 필요 없는 길(직원이 '현재 호출 번호'만 입력)이 가장 빨라요.
2. **가장 빠른 용인 시범:** 의원 1곳 + QR로 여는 웹 화면 + 문자 없음. 이 구성은 환자 개인정보를 받지 않아요. 문자는 2단계로 미뤄요.
3. **차별화는 기능 수가 아니라 "틀린 숫자를 절대 보여주지 않는 것"과 "앱 설치 없이 숫자 하나만 크게"**예요.

## 1. 실제 병원 순번 데이터를 받는 기술 경로
| 순위 | 경로 | 필요한 것 | 장점 | 위험·미확인 |
|---|---|---|---|---|
| 1 | **직원 입력(B)**: 원무과가 진료실별 '현재 호출 번호'만 태블릿에 입력 → 내 앞 인원 = 내 접수번호 − 현재 호출 번호 | 병원 동의, 접수번호가 순서대로 호출된다는 합의 | EMR·업체 계약 불필요, 가장 빠름 | 우선 진료(응급·소아·예약)로 순서가 바뀌면 틀림 → 병원이 "순서 예외 시 직원이 직접 앞 인원을 고친다"에 동의해야 함. 직원 업무 증가 |
| 2 | **순번 시스템 업체 연동(A)**: K-MOS·큐어링크 등이 병원 동의 하에 호출/취소 이벤트(웹훅)나 현재 순번 조회를 제공 | 업체 파트너 계약, 병원 동의 | 직원 추가 입력 없음 | 공개 자료에 외부 API **미확인**. 업체 답변 전에는 불가 |
| 3 | **병원 IT 담당 직접 제공**: 병원이 자기 시스템에서 순번 변경을 우리 수신 주소로 서명해 전송(최소 데이터) | 병원 IT 역량·개인정보 위수탁 계약 | 업체 우회 | 병원 규모가 작으면 IT 인력 없음 |
| 4 | **EMR 업체 연동**(똑닥 방식) | EMR 업체 계약 | 접수·대기 모두 자동 | 2018년 보도에 따르면 똑닥(비브로스)은 국내 주요 EMR 업체 8곳·지역 EMR 4곳과 **독점 계약**을 맺었다고 함 → 효자가 같은 업체 API를 쓸 수 있는지 **현재 미확인**(보도는 8년 전). 대형 EMR 업체는 막혔을 가능성을 전제로 계획 |

권고하지 않는 길: 병원 전광판·키오스크 화면을 카메라/크롤링으로 읽기(비공식, 정확도·법적 책임 불명).

## 2. 가장 빠른 용인 시범 (단계는 제 추정, 미검증)
| 단계 | 내용 | 개인정보 | 선결 승인 |
|---|---|---|---|
| 0 | 후보 의원 1~2곳 선정(어르신 환자가 많은 내과·이비인후과 등), 질문서 확정 | 없음 | 준식님: 첫 연락 승인 |
| 1 | 원장·원무 설명 + 직원 보드 시연(가상 번호). 병원 동의서 | 없음 | 병원 동의 |
| 2 | **화면만 시범**: 접수 때 QR을 안내 → 환자 폰에서 웹 화면(설치 없음) → 내 접수번호만 입력 → '내 앞 N명 + 갱신 시각'. 문자 없음 | 접수번호만(이름·전화번호 수집 없음) | 병원 동의, 문구 법률 검토 |
| 3 | 효과 측정: 원무 문의 횟수, 호출 시 부재, 어르신 이해도(5초 시험) | 없음 | — |
| 4 | **문자 추가**: 본인이 직접 번호 입력+동의, 발송 업체(SENS 등) 계약, 발신번호 등록 | 전화번호(동의 필요) | 준식님 별도 승인, 법률 검토 |

시작 후 단계 2까지 가장 빠르게 간다는 뜻이며, 병원 승낙 속도가 일정을 좌우해요. 날짜는 약속하지 않아요.

## 3. 어르신에게 더 편한 차별화 (가설 — 파일럿에서 측정)
1. **설치·가입 없음:** QR → 웹 화면. 숫자 하나(내 앞 N명)를 화면 절반 크기로.
2. **틀린 숫자 안 보임:** 갱신 2분 초과·누락·순서 변경 때 숫자를 숨기고 "병원 안내를 확인하세요" (v2 엔진에 구현, 시험됨).
3. **마지막 갱신 시각을 항상 표시**, 광고 없음.
4. **문자 실패를 화면이 알림:** 문자가 안 가면 화면에 "문자가 도착하지 않았어요" 표시(구현됨). 문자만 믿다 놓치는 일 방지.
5. **보호자 보기(2단계 이후):** 환자 본인이 동의할 때만 자녀가 볼 수 있는 링크. 자동 전달 금지.
6. **병원에게 주는 이득을 숫자로 증명:** 문의 전화 감소·호출 부재 감소를 파일럿에서 측정(현재 근거 없음).
경쟁 앱의 구체적 약점은 개별 리뷰 근거라 일반화하지 않아요.
