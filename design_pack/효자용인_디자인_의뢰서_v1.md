> 이 문서와 함께 `hyoja_design_images_v1.zip`(화면 사진, 로고 시안, 참고 이미지)을 GPT에 첨부해 주세요.

## 0. 한 줄 요약
어르신(65세 이상)과 그 자녀(30~60대)가 쓰는 **무료 시니어 정보 웹앱**. 지금은 용인시 전용이고, 앞으로 **전국 지역**(수원·성남 등)으로 넓힐 예정. 화면 틀(템플릿)은 하나이고 지역별 자료만 바뀐다. 사이트는 개인이 만든 것이며 용인시청과 무관(화면 상단·하단에 고지).

- 사이트 주소(현재): https://ljs2246.github.io/hyoja-yongin/ (아직 공개 전, 이름·도메인 미정)
- 기술: 순수 HTML 정적 페이지(GitHub Pages). 휴대폰 화면 폭 360~480px이 기준.

## 1. 이용자와 사용 상황
- 직접 쓰는 사람: 어르신. 컴퓨터·스마트폰이 서툰 분이 많음 → 큰 글씨, 큰 버튼, 한 화면에 한 가지.
- 링크를 보내는 사람: 자녀(30~60대). 카카오톡으로 부모님께 보냄 → 「가족에게 이 화면 보내기」가 핵심.
- 가장 중요한 순간: 급할 때(119, 병원, 약국), 전화 걸기.

## 2. 반드시 지킬 원칙 (디자인이 바꾸면 안 되는 것)
1. 글자는 크게: 본문 19px 이상, 버튼 글자 18~20px, 작은 글씨(출처·확인한 날)도 16px 이상.
2. 버튼 높이 56px 이상(전화 버튼), 52px 이상(지도 버튼). 누르는 곳은 한눈에 보이게.
3. 색만으로 구분하지 말 것(글자·아이콘 같이). 글자 대비는 진한 갈색(#3B2314)과 크림 배경 유지.
4. 어려운 말 금지. 말투는 「~해요」 체.
5. 출처와 「확인한 날」을 모든 안내 아래에 표시. 내용(숫자·전화번호·기관명)은 공식 자료로 확인한 것이므로 **디자인 과정에서 바꾸거나 지어내지 말 것**.
6. 광고 영역은 「광고」 표시를 분명히(법적 문제 방지). 지금은 (주)청백종합건설 광고 1건.
7. 지역 이름이 바뀌어도 같은 틀이 유지되어야 함(지역명·지역 로고 자리 필요).
8. 기존 유명 상표·캐릭터·로고와 비슷하게 만들지 말 것. 새로 창작.

## 3. 화면 구성 (사이트맵)
모든 화면 공통: 맨 위 안내띠 → 글자 크기 막대(보통/크게/아주 크게) → 소리로 읽어 주기 막대 → 버튼 소리(켜짐/꺼짐 + 크기) → 본문 → 운영자 정보(푸터) → 맨 아래 메뉴(홈·나들이·건강·일자리·복지·전체, 6칸. 좁은 화면은 3칸씩 2줄).

## 5. 로고 진행 상황
- 현재 사이트 로고: 빨간 도장 「효」 + 카네이션(이전 버전).
- 방향 합의: **「효자 용인」 글자 없이 도장 모양 「효」 하나 + 카네이션**. 이름은 아직 미정(「효자」 중심 + 지역명을 뒤에 붙이는 방식 검토).
- 시안(zip의 logo 폴더): 도장 6가지, 카네이션 포함 6가지. 사용자가 고른 도장: **「테두리 낙관(안쪽 흰 테두리) + 위쪽 카네이션」**.
- **사용자 불만:** "카네이션이 이쁘지 않고 이상하다." 원인 미확인(복잡함 / 너무 작음 / 떠 있는 느낌 / 색 / 다른 꽃 같음). → 이 부분을 가장 먼저 개선해 주세요.
- 요구: 입체감(3D), 어르신 눈에 잘 띄는 선명함, 작은 크기(휴대폰 아이콘 192px)에서도 읽힘, 흰 바탕·크림 바탕·진한 바탕에서 모두 사용, 배경 투명 PNG와 벡터(SVG) 둘 다.
- 지역판 로고: 도장은 고정하고 아래/옆에 지역 이름(예: 용인, 수원)을 붙이는 규칙.

## 6. GPT에게 요청할 일 (우선순위)
1. 도장 「효」 + 카네이션 로고 3~5안 (위 5번 요구 반영, 꽃을 더 예쁘고 단순하게).
2. 홈 화면 개선안: 큰 글씨·큰 버튼 원칙 유지하면서 더 보기 좋고 믿음직하게. 지역 선택 영역 포함(지금은 동작 안 하는 임시 버튼).
3. 정보 카드(복지·일자리 등) 디자인 통일안: 태그·제목·표·전화 버튼의 위계.
4. 급할 때 화면: 119·병원·약국이 가장 먼저 보이는 구성.
5. 공유 이미지(카카오톡 미리보기, 1200×630)와 휴대폰 홈 화면 아이콘(512px).
6. 전국 지역 확장용 규칙: 지역 이름 표시, 지역 색상 변주 여부(기본은 같은 색).

**결과물 형식:** 이미지(PNG)와 가능하면 SVG, 색상 코드·글꼴·크기 값을 표로 함께. 코드로 줄 때는 이 사이트가 순수 HTML(+인라인 스타일)이므로 외부 라이브러리 없이.
