# 효자 Google Play / Apple App Store 출시 준비표 v0.1
기준: 2026-10-29. 시험 브랜치의 사전 준비 문서. 계정 생성, 결제, 업로드, 심사 제출, 운영 배포는 미실행.
대상: 용인 정식 서비스. 웹 견본이 설치형 앱으로 완성되었다고 가정하지 않음.

## 공통 필수
- [ ] 출시 주체(개인/법인)와 브랜드명/상표 사용권 확인
- [ ] Android/iOS 기술방식 결정(네이티브/크로스플랫폼/웹 래퍼). 웹뷰 단순 포장만으로 심사 통과를 보장하지 않음
- [ ] 앱 ID/번들 ID, 서명 키/인증서, 빌드·버전·복구 책임자 지정
- [ ] 실제 Android/iPhone 설치 및 기능 검사: 지도, 길찾기, 전화, 글자 확대, 권한 거부, 오프라인, 오류, 접근성
- [ ] 공식기관 데이터 출처·기준일 표시; 검증되지 않은 병원/약국의 영업 중 표시 금지
- [ ] 개인정보 처리방침 공개 URL 및 앱 내부 접근; 위치정보, 연락처, 사진, 워치 등 실제 사용하는 권한만 요청
- [ ] 데이터 수집/공유/보관/삭제, SDK/분석 도구, 계정 탈퇴 필요 여부 조사 후 각 스토어 선언 작성
- [ ] 의료 관련 표현·비의료기기 고지 등 앱 기능에 맞는 정책 검토
- [ ] 고객지원 이메일/문의 방법, 이용약관, 오류 신고 및 긴급 문의 경로
- [ ] 스토어 소개문, 로고, 아이콘, 스크린샷, 개인정보/의료 고지, 심사용 설명 작성
- [ ] 배포 중단/긴급 공지/이전 버전 복구 및 앱 심사 반려 대응 계획

## Google Play
- [ ] 개발자 계정 존재 여부/유형/생성일 확인
- [ ] 신규 개인 계정(2023-11-13 이후)인 경우 최소 12명 14일 연속 비공개 테스트 및 프로덕션 액세스 신청 계획
- [ ] Android App Bundle(AAB) 서명, 타깃 API/권한/SDK 정책, 데이터 보안, 건강 앱 선언 확인
- [ ] 내부/비공개 테스트 후 심사 신청(승인 필요)
공식: https://support.google.com/googleplay/android-developer/answer/14151465?hl=ko
공식: https://support.google.com/googleplay/android-developer/answer/18258653?hl=ko

## Apple App Store
- [ ] Apple Developer Program 계정 및 App Store Connect 권한 확인
- [ ] iOS 앱 빌드, 실제 iPhone 테스트, TestFlight 베타 테스트
- [ ] 앱 개인정보 라벨, 공개 개인정보 처리방침, 심사용 데모 계정/접근 경로(해당 시)
- [ ] Apple 심사 지침, 앱 완성도 및 기능성, 정확한 메타데이터 확인
- [ ] 심사 제출(승인 필요)
공식: https://developer.apple.com/app-store/review/guidelines/
공식: https://developer.apple.com/app-store/app-privacy-details/

## 출시 게이트
1. 의료정보 검증 및 안전한 공개 정책 통과
2. 실제 Android/iOS 주요 기능 테스트 통과
3. 개인정보/스토어 신고와 필수 서류 완비
4. 사용자 최종 승인
5. 각 스토어 심사 승인 (소요시간 보장 불가)

## 아직 확인되지 않은 점
- 설치형 앱 소스/패키지 존재 여부
- Play Console / Apple Developer 계정 상태
- 개인정보 처리방침 실제 공개 URL
- 앱이 사용하는 실제 개인정보/SDK/권한
- 스토어 제출용 에셋 완성도
