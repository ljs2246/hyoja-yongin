# 어르신 관점 첫 화면 사용성 재검토 (피트 요청 4번, 2026-10-30)
**방법과 한계:** 화면 측정(360×800 폰 흉내)과 전문가식 점검입니다. **실제 어르신 시험은 하지 않았습니다(미검증)** → 실기기 체크리스트 30번에서 확인.

## 1. 요약
점검으로 안전과 직결되는 결함 1건을 찾아 고쳤습니다. 급할 때 화면의 큰 119·112·129 카드가 **눌러지지 않는 글자 상자**였습니다(실제 전화 버튼은 화면 1,889px 아래). 이제 카드 자체가 전화 링크입니다. 그 외 첫 화면 순서·글자 대비·중복 저장도 고쳤고, 디자인 변경이 필요한 4건은 승인 대기로 남겼습니다.

## 2. 목표까지 눌러야 하는 횟수 (측정)
| 하고 싶은 일 | 누르는 횟수 | 비고 |
|---|---|---|
| 119 전화 | 2번 (첫 화면 「급할 때」 → 큰 119 카드) | 수정 전: 119 카드가 안 눌려 스크롤 1,889px 필요 |
| 가족에게 전화 | 1번(저장된 경우) | 처음 저장은 4번(＋가족 저장하기→이름→번호→저장하기) |
| 복지·혜택 / 이동·교통 | 1번 | |
| 글자 크게 | 1번(첫 화면) | 다른 화면은 위쪽 글자 크기 줄 |
## 3. 측정값
- 첫 화면에서 「급할 때」 위치 y=333px(첫 화면 안, 수정 전: 가족 카드 뒤라 가족 3명 저장 시 y=1,000px 이상으로 밀림).
- 4개 핵심 위치: 가족 0명일 때 복지 y=776, 교통 870 / 3명일 때 복지 953, 교통 1,047 → **4개가 한 화면에 모두 보이지는 않음(1.3화면 분량)**.
- 모든 누르는 곳 높이 ≥ 44px(전부), 최소 글자 16px(수정 전 14px), 글자 대비 4.5:1 이상(수정 전 하단 메뉴 선택 칸 2.68:1·급할 때 배너 3.93:1).
## 4. 수정한 것 (테스트 브랜치)
1. 급할 때 화면 119·112·129 카드 → 전화 링크 + 「눌러서 전화 걸기 ›」 (출처·확인일 표시 유지).
2. 첫 화면 순서: 급할 때 → 가족 전화 → 복지·혜택 → 이동·교통.
3. 대비·글자: 하단 메뉴 선택 칸 색을 진하게, 급할 때 배너 윗색 약간 진하게, 안내 글자색, 작은 글자 14~15px→16px. 로고·구성은 그대로.
4. 같은 번호를 두 번 저장하면 「이미 저장된 번호예요」.
## 5. 남은 제안 (디자인 변경이라 승인 대기)
| # | 내용 | 이유 |
|---|---|---|
| a | 첫 화면 위쪽 「글자 크기」+「소리 설정」(약 250px)을 한 줄로 줄이거나 아래로 | 4개 핵심을 한 화면에 더 가까이 |
| b | 「가족 저장」 안내에 「자녀분이 설정해 드릴 때」 한 줄 | 어르신 혼자 입력은 어려움(입력 3칸) |
| c | 중간 화면(전체 메뉴→나들이)의 「← 처음 화면으로」가 한 단계 뒤가 아니라 처음으로 가는 점 | 혼동 가능, 어르신 시험으로 확인 후 「← 뒤로」 추가 여부 결정 |
| d | 하단 「가족 전화」와 「홈」이 같은 화면으로 가서 헷갈릴 수 있음 | 시험 후 하나로 합칠지 결정 |
## 6. 미검증
실제 어르신 시험, 실기기 터치 감각, 외부 글꼴·날씨 호출(오프라인 동작은 모의 통과), 소리 읽기 품질.
