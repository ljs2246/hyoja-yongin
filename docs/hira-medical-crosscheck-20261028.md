# 용인 의료기관 HIRA 교차검증 실행 기준 (2026-10-28)

## 공식 근거
- HIRA 전국 병의원 및 약국 현황: https://www.data.go.kr/data/15051059/fileData.do
- 2026-09-30 기준 분기 추출 자료, 2026-10-19 등록 / 2026-10-20 수정. 10월의 현재 운영상태를 보증하지 않음.
- HIRA 공식 안내: https://www.hira.or.kr/bbsDummy.do?brdBltNo=12040&brdScnBltNo=4&pageIndex=1&pgmid=HIRAA020002000100
- 병원정보 API: https://www.data.go.kr/data/15001698/openapi.do

## 데이터 소스별 역할
- 국립중앙의료원: 현재 앱 응급기관 5, 약국 441의 수집원천. 수집 성공 ≠ 현재 운영 확인.
- HIRA: 병의원·약국 신고현황과 이름·주소 교차확인. 파일은 분기 기준, API는 접근권한과 갱신주기 확인 필요.
- 행정 인허가: 개업/휴업/폐업/이전 등 법적 운영상태. 최신 개별 기록 대조가 필요.
- 기관 공식 안내: 전화, 운영시간, 임시휴무와 방문 가능 여부. 실시간 영업은 별도.

## 단계별 작업
1. 현재 446건을 hpid, 기관명, 주소, 좌표, 전화, 수집일과 함께 별도 검증표로 추출한다.
2. HIRA와 이름·주소의 정규화 비교를 수행하고 동일 이름·다른 주소, 다른 이름·동일 주소를 별도 충돌로 표시한다.
3. 최신 인허가 원본에서 관리번호, 영업상태, 폐업/휴업/이전일, 기준일을 대조한다. 암호화된 HIRA 요양기호와 hpid의 동일성을 추측하지 않는다.
4. 주소 좌표는 지오코딩 또는 공식 지도와 비교한다. 좌표가 대한민국 범위 안이라는 이유만으로 일치 판정하지 않는다.
5. 전화번호 18건, 중복 4묶음(9기록), 2500 시간표 2기관을 우선 검토한다.
6. 날짜와 근거 URL을 저장하고 미확인·공식자료 충돌·공식 원문 일치·휴폐업 확인으로 구분한다.
7. 운영 앱은 승인 전 변경하지 않는다.

## 이 문서 작성 시점 결과
공식 HIRA 자료의 출처, 기준일, API 안내 확인 완료.
446개 기관별 HIRA 및 인허가 행 일대일 대조는 아직 미실행. 운영상태 확정 건수 0건(이번 교차검증으로 새로 확정한 건수).
