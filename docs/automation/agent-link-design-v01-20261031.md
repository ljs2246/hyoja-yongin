## 2. 공동 작업 구조 안
### 2-1. 우편함 방식 비교
| 방식 | 장점 | 단점 | 의견 |
|---|---|---|---|
| A. 이슈 1건 = 지시 1건(댓글로 보고) | 알림·검색·상태 표시(라벨) 쉬움, 번호 자동 부여 | 공개 저장소라 외부 열람 | **권장** |
| B. 파일 주고받기(docs/comms/*.md, PR로 병합) | 변경 기록 정확 | 병합 절차 무거움, main 보호 미설정 | 보관용으로만 |
| C. Drive만 사용(현행) | 준식님이 읽기 편함 | 자동화 불가, 번호 중복 발생 | 보관함으로 유지 |

### 2-2. 이슈 머리말(서명) 규칙
모든 지시·보고의 첫 줄에 아래 4줄을 넣습니다. 글쓴이가 같은 계정이어도 구분하기 위한 것입니다.
```
발신: 피트 | 클로드 | 준식님
수신: 피트 | 클로드 | 준식님
문서번호: 047 (번호표 기준)
승인 상태: 승인 전 | 준식님 승인(날짜·원문 인용)
```
- 「준식님 승인」은 준식님이 채팅이나 이슈에 직접 남긴 문장을 인용할 때만 표기합니다. AI가 AI의 승인을 대신 쓰지 않습니다.

### 2-3. 라벨(상태 표시)과 흐름
`지시초안 → 승인대기 → 진행 → 보고 → 검수 → 종료` (+ `보류`, `수정필요`).
- `승인됨` 라벨은 **준식님만** 붙입니다(권한상 가능한 사람은 저장소 관리자). 자동 연결이 생겨도 이 라벨이 없으면 아무것도 실행하지 않습니다.
- 보고 형식은 기존 합의대로 **완료 / 미확인 / 보류 / 수정 필요**로 묶습니다.

### 2-4. 이슈에 쓰면 안 되는 것(공개 저장소)
개인정보, 환자 정보, 사진, 비밀번호·열쇠값, 계약·단가, 미확정 전화번호 원문(번호 대신 항목 이름으로 지칭), 실기기 시험자 실명.

## 5. 연결에 필요한 API·인증·비용·보안
용어: API(프로그램끼리 대화하는 창구), 토큰/열쇠값(비밀번호 대신 쓰는 긴 문자열), 시크릿(GitHub에 안전하게 숨겨 저장하는 비밀값), 권한(그 열쇠로 할 수 있는 일의 범위).
### 5-1. 구성 요소
| 요소 | 용도 | 인증 방식 | 비용 |
|---|---|---|---|
| GitHub 이슈·저장소 API(gh) | 지시·보고 읽기/쓰기 | ① 실행 중 자동 발급되는 임시 열쇠(GITHUB_TOKEN, 권한을 파일에 명시) ② 저장소 한 곳 전용 개인 열쇠(만료일 설정) ③ GitHub App(봇 전용 신분증) | GitHub API 자체는 무료로 알고 있으나 한도 수치는 미확인 |
| 클로드 자동 실행(공식 `claude-code-action`) | 이슈의 `@claude` 또는 라벨을 받아 작업 | 저장소 시크릿에 `ANTHROPIC_API_KEY`(사용량 요금) 또는 `CLAUDE_CODE_OAUTH_TOKEN`(구독, 열쇠를 만든 사람 개인 구독에 묶임) | **API는 사용한 만큼 과금**, 금액 추정치는 사용량 자료가 없어 **미확인**. 구독 열쇠는 개인 계정에 묶여 공동 사용에 부적합 |
| 클로드 GitHub App 설치 | 위 자동 실행의 신분증 | 저장소 관리자 권한 필요 | 설치 자체 비용은 문서에 없음. **권한을 일부만 고를 수 없고** Actions·Workflows 쓰기, 관리자 읽기 등 넓은 권한이 한 번에 부여됨. 최소 권한이 필요하면 내용·이슈·PR만 가진 직접 만든 App 사용 |
| 피트 쪽 연결 | 피트가 이슈를 읽고 쓰는 방법 | **미확인**(피트가 사용하는 도구·계정·열쇠를 피트가 기재) | 미확인 |
### 5-2. 이 구조에서 특히 조심할 점
| 위험 | 내용 | 대응 |
|---|---|---|
| AI끼리 무한 대화 | 공식 도구는 봇 계정 글에는 기본으로 반응하지 않음(`allowed_bots`로 허용 가능). 피트가 봇 계정이면 막히고, 허용하면 서로 부르는 반복 위험 | 한 이슈당 실행 횟수 1회, `--max-turns`·시간 제한·동시 실행 1건 |

| main 보호 없음 | AI가 잘못 올려도 막는 장치 없음 | 자동화 허용 경로를 시험 브랜치(test/*)와 docs/로 제한, main 직접 쓰기 금지. 보호 규칙은 기존 승인 대기 항목 |
| 비밀값 유출 | 열쇠를 글·커밋에 쓰면 공개됨 | 시크릿에만 저장, 이슈·로그 출력 금지, 유출 시 즉시 폐기 |
| 비용 폭주 | 반복 실행 | 콘솔 월 한도, 실행 횟수 상한, 이상 시 워크플로 비활성화(긴급 정지 스위치) |
