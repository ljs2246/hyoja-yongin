# 내 지역·부모님 지역 저장 기반
작성일: 2026-10-26
상태: 공통 모듈 구현, 합성 자료 검사 12개 통과. 운영 UI 연결 전.

## 구현
- 내 지역·부모님 지역을 독립 저장하고 최근 선택한 구분을 복원.
- 검증된 지역 목록에 없는 식별자는 저장 거부.
- 저장 후 목록에서 삭제된 지역은 복원하지 않고 재선택 대상으로 처리.
- 브라우저 저장을 사용할 수 없어도 현재 화면 메모리에서는 선택 유지.
- 저장 실패를 persistent=false로 반환해 화면에서 안내할 수 있음.
- 위치 좌표·상세 주소·부모님 개인정보는 저장하지 않음.
- 두 지역 초기화는 독립 동작.

## 공식 지역 자료 경로
행정안전부 행정표준코드 법정동코드 API 안내:
https://www.data.go.kr/data/15077871/openapi.do
행정표준코드 검색 안내:
https://code.go.kr/stdcodesrch/CodeSearchGuide.do

공식 서비스 경로를 찾았다는 뜻이며 전국 최신 코드 원본 확보·검증 완료가 아님.
기존 의료 데이터 API 인증키가 이 서비스에도 유효하다고 가정하지 않음.
법정동코드·행정동코드·기관코드를 섞지 않으며 원천별 대응 관계를 확인해야 함.
현재 테스트의 TEST_A·TEST_B는 합성 식별자임. 실제 지역코드로 게시하지 않음.

## 화면 연결 시 지켜야 할 사항
- 저장 실패 시 ‘이 기기에서 지역 저장을 사용할 수 없어요. 현재 화면에서는 이용할 수 있어요.’ 안내.
- 삭제·폐지된 지역은 다른 지역으로 임의 변경하지 않고 다시 선택하도록 안내.
- 선택 구분과 현재 지역을 모든 결과 화면에 명확히 표시.
- 지역 변경 시 결과를 즉시 비우고 region-core의 응답 토큰 검사를 적용.
- 현재 운영 용인 콘텐츠와 미확보 지역 콘텐츠가 섞이지 않도록 검수 후 연결.
