# 개인정보 처리방침 초안 (게시 전 검토용 · 법률 전문가 확인 필요)

「효자 용인」은 가입·로그인이 없는 안내 사이트예요. 이름, 전화번호, 주소 같은 개인정보를 받지 않아요.

1. **통계(켜는 경우에만)**: 어떤 화면이 얼마나 쓰이는지 알기 위해 익명 이용 통계를 모아요. 모으는 것은 방문한 화면, 검색·전화 버튼·지도 버튼·글자 크기 버튼을 눌렀다는 횟수, 선택한 구, 화면 크기 구간이에요.
2. **모으지 않는 것**: 검색어 글자, 전화번호, 이름, 건강 정보, 정확한 위치, 쿠키, 고유 식별번호.
3. **전화 버튼 횟수**는 버튼을 눌렀다는 기록이며, 통화가 연결됐는지는 알 수 없어요.
4. **통계 서비스**: GoatCounter(goatcounter.com). 개별 방문 기록이 아닌 집계 값을 저장한다고 안내하고 있어요.
5. **다른 외부 서비스**: 날씨(Open-Meteo, 고정된 용인 좌표만 전송), 글꼴(Google Fonts — 접속 정보가 구글에 전달될 수 있어요).
6. **거부 방법**: 브라우저의 "추적 안 함(Do Not Track)" 설정을 켜면 통계를 보내지 않아요.
7. **문의**: hyoja.yongin 운영팀(화면 하단 메일).
8. 이 방침은 바뀔 수 있고, 바뀌면 이 화면에 날짜와 함께 알려요.

※ 초안입니다. 게시 전에 법률 전문가 확인과 대표 승인이 필요해요.
