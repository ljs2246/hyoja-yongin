# 개인정보 처리방침 초안 v3 — 법률 검토용 (비공개 · 게시 금지 · 대표 승인과 전문가 검토 전)

작성 주체는 법률 자문 자격이 없는 AI예요. 아래 "검토 요청 사항"은 **법적 결론이 아니라 전문가께 확인받을 질문**이에요.

## A. 사실 정리 (2026-11-08, 시험 브랜치 8b2bc61 이후 실측)
| 번호 | 사실 | 근거 |
|---|---|---|
| 1 | 가입·로그인·입력 저장 기능이 없어요. 이름·전화번호·주소를 받지 않아요 | 코드·모의 브라우저 시험 |
| 2 | 화면을 열면 자동 접속하는 외부 서비스는 Open-Meteo 날씨·대기질 2곳뿐이에요 | 실측(`docs/external-connections-v1.md`) |
| 3 | 글꼴은 사이트에 직접 담았고 구글 서버에 접속하지 않아요(Noto Sans KR, SIL OFL 1.1) | 요청 0건 시험 |
| 4 | 익명 통계는 **코드가 비어 있어 꺼져 있어요.** 켜면 허용 이름 목록 값만 GoatCounter로 보내요 | footer.js, 통계 시험 |
| 5 | 사용자 기기에는 글자 크기 설정과 오프라인 저장본이 저장돼요(쿠키 없음) | 시험 |
| 6 | 호스팅 사업자(추정: GitHub Pages)가 서버 접속 기록을 갖는지는 **확인하지 못했어요** | 증거 미확인 |

## B. 처리방침 본문 초안
(`privacy-policy-draft-v2.md`의 1~8항을 그대로 쓰되 아래를 보완)
1. **운영자 정보**: 상호(또는 성명), 연락처, 개인정보 관련 문의 담당 — (대표가 기재)
2. **자동 수집 접속 정보**: 외부 서비스(Open-Meteo, 통계를 켜는 경우 GoatCounter)와 호스팅 사업자의 서버에는 인터넷 접속 시 일반적으로 IP 주소·브라우저 정보가 도달할 수 있어요.
3. **국외 서버**: Open-Meteo·GoatCounter 서버의 소재국은 **확인하지 못했어요**(개설·확인 후 기재).
4. **어린이**: 이 사이트는 어르신 대상이며 아동 정보를 수집하지 않아요.
5. **이용자 권리와 거부**: 추적 거부(Do Not Track, GPC) 신호 시 통계 미전송, 기기 저장값 삭제 방법 안내.
6. **변경 고지**: 시행일과 변경 이력.

## C. 전문가께 확인받을 질문
| # | 질문 | 왜 필요한가 |
|---|---|---|
| 1 | IP 주소가 서버에 도달만 하고 저장하지 않는 경우에도 처리방침 고지 대상인가? | 날씨 서비스는 현재도 동작 중이라 통계 여부와 무관해요 |
| 2 | 해외 서비스(Open-Meteo, GoatCounter)로의 접속 정보 도달이 국외 이전 고지 대상인가? | 서버 소재국 미확인 |
| 3 | 통계를 켜지 않고 날씨만 있는 지금 상태에서 처리방침이 필수인가, 권고인가? | 게시 시점 결정 |
| 4 | 쿠키·식별자 없이 집계 값만 보내는 경우 동의 배너가 필요한가? | 동의 절차 설계 |
| 5 | 전화 버튼 클릭 횟수 같은 집계가 개인정보에 해당할 가능성은? | 수집 항목 표기 방식 |
| 6 | 보관 기간(GoatCounter, 호스팅)을 어떻게 표기해야 하나? | 현재 미확인 |
