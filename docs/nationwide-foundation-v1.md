# 전국 지역 공통 기반 · 1차 구현
작성일: 2026-10-26
상태: 공통 로직과 합성 자료 테스트 완료. 운영 페이지 연결 전.

## 구현 범위
- 지역 상위·하위 관계로 선택 지역에 속한 기관만 조회.
- 기관 종류 별도 분리: 병원·의원·응급기관·약국·공공기관·보건소·복지기관 등.
- 기관 통합 식별자와 원천 식별자를 별도 관리.
- 주소 지역코드와 기관 지역코드 불일치, 위치·분류 검증 근거 누락은 게시 보류.
- 동명·동일 주소 중복은 자동 병합하지 않고 게시 보류 목록으로 반환.
- 전국 공통 제도와 해당 광역·기초 지역 제도의 적용 범위 분리.
- 지역 변경 및 같은 지역의 새 검색 이후 이전 응답을 차단.
- 지역을 바꿨다가 되돌아온 경우에도 이전 응답을 차단.

## 검증
실행: node scripts/test-region-core.cjs
24개 검사 통과. TEST_ 접두어의 가상 지역·기관만 사용.
실제 지역코드, 실제 기관 위치, 실제 복지 자격 또는 전국 자료 수집을 검증한 결과가 아님.
테스트에서 사용하는 verified 플래그와 example.invalid 출처는 합성 자료이며 실제 검증 근거로 사용하지 않음.

## 연결 전 남은 작업
1. 공식 지역코드 체계와 원천 지역 항목 대응표를 확보·확인.
2. 기관 원천별 식별자 및 통합 기관 식별자 매핑, 기관 분류·주소 지역 검증.
3. 지역코드 누락·미등록·분류 미정 자료를 수집 단계의 별도 보류 기록으로 관리.
4. 데이터 구조 예시를 운영 자료 형식과 연결하고 필드별 검증 근거 저장.
5. 지역 변경 즉시 화면 목록을 비우고 공통 로직의 응답 검사 결과에 따라 렌더링.
6. 내 지역·부모님 지역을 따로 저장하는 UI 연결 및 기기별 검수.
7. 전국 전체 자료가 확보되기 전에는 제공 지역·기능 범위를 명시.

## 공개 정책
현재 코드는 운영 HTML에서 로드하지 않음. 기존 용인 서비스 동작을 바꾸지 않음.
검증 근거가 없으면 플래그를 임의로 true로 지정하지 않음.
등록 형식 검사와 기관의 실제 존재·운영 검증을 구분.
화면 전환·새 지역 정보 게시 전 구체적 결과를 사용자에게 제시.
