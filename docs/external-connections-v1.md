## B. 사용자가 링크·버튼을 눌러야 이동하는 곳 (자동 접속 아님)
- 지도: map.naver.com, map.kakao.com / 앱 설치: apps.apple.com, play.google.com
- 공공·기관 안내 링크: www.yongin.go.kr 외 약 25곳(구청, 복지·보건 기관, 문화시설 등)
- 이 링크들은 눌렀을 때 해당 사이트의 정책이 적용돼요. 앱은 누른 내용을 저장하지 않아요(통계를 켠 경우 지도 버튼은 "눌렀다"는 횟수만 기록).

## C. 저장하는 것
- 사용자 기기: 글자 크기 설정과 오프라인 저장본(서비스워커 캐시). 개인 식별 정보 없음.
- 서버(사이트): 개인정보 저장 없음. 가입·로그인·입력 저장 기능 없음.
