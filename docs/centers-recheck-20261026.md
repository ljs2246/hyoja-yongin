## 원문 대조 완료 7곳
풍덕천1동·신봉동·죽전1동·죽전2동·죽전3동·상현1동·상현3동.
공식 페이지의 담당부서·전화번호와 앱 표시 번호가 일치함을 확인.
공식 페이지 담당 연락처라는 의미이며 민원·복지 업무 모두의 대표번호라고 확정하지 않음.
수지구청 메뉴·하단 공통 구청 대표번호와 동별 담당 연락처를 구분해 대조.

## 공식 페이지 간 차이
- 포곡읍: 앱5531. 직원안내 검색 결과에5531이 존재하나 찾아오시는 길과 읍소식 페이지는5530이 표시됨. 팀장/직원 업무 차이 가능. 현재 번호 무효로 판단하지 않음.
- 이동읍: 앱5691. 일부 공식 페이지·주민자치센터 연결 영역에는5691, 현재 일반현황·행정구역 페이지에는5692가 나타남. 담당 용도 차이·갱신시점 미확인.
- 성복동: 앱8777. 인사말 페이지는8777, 오시는 길·연혁 페이지는8772. 현재 번호 무효로 판단하지 않음.
전화번호를 일괄 교체하지 않았음. 특히 주민자치센터 수강 문의와 행정복지센터 일반·복지 문의는 혼동하지 않음.

## 원문 접속 결과와 다음 조건
처인구13개 원문과 수지구 일부 원문 조회는 시간초과/게이트웨이 오류로 원문을 확보하지 못함.
검색 결과에 번호가 있어도 원문 직접 대조 완료와 구분. 오류는 이 조회 환경의 제한이며 기관 사이트가 영구 중단되었다고 판단하지 않음.
다음 재확인: 공식 원문이 조회될 때 담당 업무·전화번호·페이지 수정시점을 확인. 충돌3곳은 직원업무안내와 안내 페이지를 함께 비교.
기관에 직접 전화를 걸거나 외부 문의를 보내지 않았음.
기존39개 실제 전화링크와 표시번호 일치는 이전 검사에서 확인했지만 번호 최신성·실제 연결 성공과는 다름.
