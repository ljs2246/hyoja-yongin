# 개인정보 처리방침 초안 v2 (비공개 초안 · 게시 전 법률 전문가 확인과 대표 승인 필요)

「효자 용인」(이하 "이 사이트")은 가입·로그인이 없는 안내 사이트예요. 이름, 전화번호, 주소, 건강 정보 같은 개인정보를 입력받거나 저장하지 않아요.

## 1. 이 사이트가 처리하는 정보
| 구분 | 내용 | 목적 | 비고 |
|---|---|---|---|
| 기기에 저장 | 글자 크기 설정, 오프라인 저장본 | 편하게 보기, 인터넷이 끊겨도 열기 | 사용자의 기기에만 있고 지울 수 있어요 |
| 익명 이용 통계(**켜는 경우에만**) | 방문한 화면, 검색·전화·지도·글자 크기 버튼을 눌렀다는 횟수, 선택한 구, 화면 크기 구간 | 어떤 안내가 필요한지 파악해 개선 | 개인을 알아볼 수 없는 집계 값 |

## 2. 모으지 않는 것
검색어 글자, 전화번호, 이름, 건강 정보, 정확한 위치(GPS·주소), 쿠키, 광고 식별자, 고유 식별번호.
검색은 "검색어를 입력했는지(예/아니오)"만 세어요.

## 3. 전화 버튼 횟수
버튼을 눌렀다는 기록이며, 통화가 연결됐는지·누구에게 걸었는지는 알 수 없어요.

## 4. 외부 서비스와 접속 정보
화면을 열면 인터넷 접속의 일반적인 과정에서 **접속 IP 주소와 브라우저 정보**가 아래 서버에 전달될 수 있어요.
| 서비스 | 용도 | 보내는 내용 |
|---|---|---|
| Open-Meteo | 오늘의 날씨·대기질 | 용인의 고정 좌표(사용자 위치가 아니에요) |
| GoatCounter (켜는 경우) | 익명 이용 통계 | 위 1번의 통계 값, 화면 폭 구간. 서비스는 IP·브라우저 정보 원본을 저장하지 않고 집계 값만 저장한다고 안내해요 |
| (참고) 글꼴 | 화면 글자 | 글꼴을 이 사이트에 직접 담아 **구글 서버에 접속하지 않아요** |
- 링크를 눌러 이동한 외부 사이트(구청, 지도 등)는 그 사이트의 방침이 적용돼요.

## 5. 보관 기간
- 기기 저장 값: 사용자가 지울 때까지(브라우저 설정에서 삭제 가능)
- 통계 값: **서비스의 보관 기간은 확인하지 못했어요.** 개설할 때 확인해 기재할 예정이에요.

## 6. 거부·삭제 방법
- 브라우저의 **"추적 안 함(Do Not Track)"** 또는 Global Privacy Control을 켜면 통계를 보내지 않아요.
- 사이트 데이터·캐시 삭제로 기기 저장 값을 지울 수 있어요.

### 검토 메모 (게시 전 삭제)
- 한국 개인정보 보호법상 고지 의무·표현은 **법률 전문가 확인 필요**. 저는 법률 자문 자격이 없어요.
- 4번 표는 `docs/external-connections-v1.md`의 실측 결과와 같아야 해요. 외부 서비스가 바뀌면 같이 고쳐요.
- 5번 보관 기간은 GoatCounter 개설 시 확인 후 기재.
- 통계를 켜지 않고 게시한다면 1번의 통계 행과 4번의 GoatCounter 행을 빼요.
