# ④ 실제 Android·iPhone 시험 체크리스트 및 기록 양식 (지시 011)
상태: **전 항목 미검증**(시험 전). 에뮬레이션 91/91은 실기기를 대신하지 않습니다.
시험 방법: 아래 순서대로 한 단계씩 하고, 결과를 기록표에 적어 주세요. 문제가 보이면 화면을 캡처해 주세요.

## 준비
1. 기기 2대 이상: Android 1(크롬), iPhone 1(사파리). 가능하면 어르신이 쓰시는 기기 1대 추가.
2. 테스트 주소는 운영 주소가 아니라 피트가 정한 테스트 주소로 합니다(운영 승인 전).
3. 글자 크기를 기기 설정에서 크게(200%) 한 상태로도 한 번 더 확인합니다.

## 시험 항목 (각각 통과/실패/해당없음)
| # | 항목 | 확인 방법 | 기대 결과 |
|---|---|---|---|
| 1 | 첫 화면 | 주소 접속 | 5초 안에 열리고 글자가 잘리지 않음 |
| 2 | 119 전화 | 응급 화면에서 119 버튼 누름 | 전화 앱에 119만 입력됨(실제로 걸지 말고 취소) |
| 3 | 병원 응급실 번호 | 세브란스·다보스 버튼 | 화면 번호와 전화 앱 번호가 같음 |

| 5 | 가족 전화 저장 | 가족 1명 저장 | 목록에 보이고 앱을 닫았다 열어도 남음 |

| 13 | 오프라인 | 비행기 모드 후 앱 열기 | 응급 화면이 열리고 119 버튼 보임, 옛 번호 없음 |

| 16 | 어르신 사용성 | 어르신께 「119 전화」를 찾아보시게 함 | 도움 없이 30초 안에 도달 |
