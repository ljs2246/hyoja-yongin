# ③ 실제 Android·iPhone 시험 체크리스트 v02 (2026-10-30, 피트 요청 3번)
v01(03-device-test-checklist.md, 16항목)은 보존합니다. 이 v02는 새 첫 화면(핵심 4개)·하단 메뉴 6칸·가족 사진·광고 화면을 반영해 **30항목**으로 늘렸습니다.
**상태: 전 항목 미검증(실기기 시험 0건).** 「모의」 열은 이 환경의 휴대폰 화면 흉내(Chromium) 결과이며 실기기를 대신하지 않습니다.

## 0. 시험 전 준비 (한 단계씩)
1. 기기: Android 1대(크롬), iPhone 1대(사파리), 가능하면 어르신이 쓰시는 기기 1대 추가. 기기 확보 방법·시험일은 승인 대기(11월 둘째 주 제안).
2. 시험 주소는 운영 주소가 아니라 피트가 정한 **테스트 주소**만 사용합니다. 운영 배포 승인 전에는 공개 주소를 만들지 않습니다.
3. 기기 설정에서 글자 크기를 「가장 크게」 한 상태로 한 번 더 시험합니다(항목 25).
4. 실제 119·병원에는 **절대 전화를 걸지 말고** 전화 앱이 열린 것만 확인한 뒤 취소합니다.
5. 가족 사진은 시험용 사진(얼굴 없는 풍경 등)을 씁니다. 실제 가족 사진은 쓰지 않습니다(개인정보).
6. 문제가 보이면 화면을 캡처해 파일명을 기록표에 적습니다.
