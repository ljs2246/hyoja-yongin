# ⑤ 롤백·킬스위치 초안 및 경보 누락 시 수동 통제 (지시 011)
상태: **초안(검수중)**. 킬스위치 코드는 테스트 브랜치에서 시험 통과(모의훈련 4-a~c). 운영 반영은 승인 후.

## 1. 킬스위치 (화면에서 특정 정보만 즉시 숨기기)
- 파일: `data/killswitch.json` (기본 `active:false`)
- 켜는 법: ① 이 파일을 열어 `active`를 `true`로, `hide`에 숨길 항목의 선택자(예: `a[data-hj-src^='공공데이터']`)를 적고 저장 ② 저장소에 올림(승인자 2인: 피트 검수+준식 승인) ③ 휴대폰에서 새로고침해 확인.
- 효과: 지정 항목이 사라지고 「일부 정보를 확인하는 중이라 잠시 가렸어요. 급할 때는 119에 전화해 주세요.」가 표시됨. 119 버튼(`data-hj-keep`)은 어떤 경우에도 유지.
- 끄는 법: `active`를 `false`로 되돌려 올림.
- 한계: 이미 오프라인 캐시를 가진 휴대폰은 한 번 온라인 접속해야 반영됩니다.

## 2. 정상 이전 버전 복구
1. `scripts/rollback-check.sh` 실행 → 깨끗한 상태에서 전체 통과한 마지막 커밋을 찾아 임시 폴더에서 다시 전체 검사(통과해야 후보).
2. 후보 확인 후 피트 검수·준식님 승인.
3. 승인 뒤 사람이 되돌림(`git revert` 권장, 강제 덮어쓰기 금지).
4. 되돌린 뒤 확인: 서비스워커 버전이 올라갔는지(구캐시 삭제), 공식정보 버전·개인정보(기기 내 저장은 영향 없음), 119 버튼.
5. 실제 복구 연습: 시범 전 1회 이상(미실시).

## 3. 경보 누락 시 수동 통제 (자동 알림은 아직 파일뿐 → 24시간 감시 아님)
| 주기 | 사람이 할 일 | 담당 |
|---|---|---|
| 매일 오전 | GitHub 「Actions」 탭에서 빨간 표시(실패)가 있는지 확인 | 피트(대체: 준식) |
| 매일 | 응급 화면에서 119·세브란스 번호 한 번 눌러 확인(통화 취소) | 준식 |
| 주 1회 | `docs/runs`의 ALERT 파일·실행 기록 확인, 권한(협력자) 목록 확인 | 피트 |
| 신고 접수 시 | 즉시 킬스위치로 해당 정보 숨김 → 원인 확인 → 승인 후 복구 | 피트→준식 |
사고 등급: P0(민감정보 노출·긴급 안내 오류·미검증 의료정보 노출)은 즉시 차단, P1은 당일, P2는 일반 수정. 개인정보 유출이 의심되면 법령상 통지 요건을 법률 검토로 확인.
