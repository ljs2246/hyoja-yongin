# 갤럭시 검수 준비 (3순위) — 대표님 컴퓨터에서 하는 일

클로드 작업 환경에는 가상기기를 돌리는 기능(KVM)과 구글 다운로드 접속이 없어 **Android Studio는 설치·실행해 보지 못했습니다.** 아래는 절차 안내이며 아직 실제로 검증되지 않았습니다.

## A. 실제 갤럭시 연결 (가장 정확, 무료)
1. 갤럭시: 설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호를 7번 눌러 개발자 모드 켜기
2. 설정 → 개발자 옵션 → **USB 디버깅** 켜기 → USB 케이블로 컴퓨터에 연결 → 폰에서 "허용"
3. 컴퓨터에 platform-tools(adb, 무료 설치 파일) 설치 후 `adb devices` 에 기기가 "device"로 보이면 성공
4. 사이트 폴더에서 `python3 -m http.server 8080` 실행, 다른 창에서 `adb reverse tcp:8080 tcp:8080`
5. 폰 크롬에서 `http://localhost:8080` 열기 → 눈으로 확인 (아래 체크표)
6. 자동 점검: `npm i playwright && node qa/android/android-smoke.cjs 1.0` (글자 배율 1.0/1.15/1.3 로 세 번)
   - 폰 글자 크기를 바꿨다가 끝나면 자동으로 1.0 으로 되돌립니다.
   - 실제 전화 걸기는 하지 않습니다.

## B. Android Studio 가상기기
1. Android Studio 설치(무료) → More Actions → Virtual Device Manager → Create Device
2. 갤럭시와 비슷한 크기(1080×2340, 약 6.1인치) + 최신 Android 이미지 선택 → 실행
3. 가상기기 크롬에서 `http://10.0.2.2:8080` (컴퓨터의 8080 포트) 열기, 또는 A-4의 adb reverse 후 localhost 사용
4. 같은 `android-smoke.cjs` 사용 가능
※ 컴퓨터가 가상화(Intel VT-x / AMD-V)를 지원해야 하고, 저장공간 약 10GB 이상 필요합니다.

## 눈으로 확인할 것 (실기기 체크표)
| 항목 | 방법 |
|---|---|
| 화면 확대 | 폰 설정 → 디스플레이 → 글자 크기와 스타일을 최대로: 가로로 밀리거나 글자 잘림이 없는지 (특히 문화 화면) |
| 터치 | 메뉴·전화·지도 버튼이 한 번에 눌리는지, 손가락 크기에 너무 작지 않은지 |
| 지도 실행 | 응급 화면 → 약국/병원 검색 → 지도 버튼 → 지도 앱/브라우저가 열리는지 |
| 전화 | 주민센터 전화 버튼은 **통화 화면까지만** 확인하고 바로 취소. 응급번호(119 등)는 절대 발신 금지 |
| 오프라인 | 비행기 모드에서 화면이 열리는지, 해제 후 정상인지 |

## 비용
Android Studio·adb·Playwright 모두 무료. 실제 기기는 대표님 폰 사용.
