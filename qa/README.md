# 효자 용인 휴대폰 자동검수

무료 도구(Playwright)만 씁니다. 파일을 고치거나 배포하지 않고, 외부로 아무것도 보내지 않습니다.

## 한 번에 실행
```
pip install playwright && playwright install chromium
python3 qa/run_qa.py              # 전체 (약 2분)
python3 qa/run_qa.py --only 전화   # 묶음 하나만: 화면 / 폭·글자 / 전화 / 검색 / 오프라인
```
결과: `qa-report/report.md`(읽는 보고서), `report.json`, `screenshots/`(실패한 항목 캡처). 실패가 1건이라도 있으면 종료코드 1.

## 검사 항목
| 묶음 | 내용 |
|---|---|
| 화면 | 14개 화면 열림, 스크립트 오류·없는 파일 0 |
| 폭·글자 | 320·360·390px × 보통·크게·아주 크게 × 14화면: 가로 넘침, 전화 칸 잘림 (1px 이내는 경고) |
| 전화 | 화면의 모든 전화 링크가 공식 확인 목록 안인지, 불일치·미확인 번호(포곡·이동·1577-1000 등)가 링크나 글자로 보이지 않는지, 주민센터 37+2 |
| 검색 | 약국 전화 0, 응급의료기관은 승인 3곳 번호만, 지도 버튼, '지금 문 연 약국' 전화 0 (주민센터는 검색창이 없어 목록 검사) |
| 오프라인 | 서비스워커, 14화면 비행기 모드 열림, 재접속 복원 |

## 기준표
`qa/qa_config.json` — 공식 확인 번호(allow)와 숨겨야 할 번호(block). 번호를 새로 공개하려면 공식 확인 + 대표 승인 후 allow에 추가하세요.

## GitHub Actions
`.github/workflows/qa-playwright.yml` — `test/**` 브랜치 푸시, main 대상 PR, 수동 실행에서 돌고, 실패하면 빨간불. 읽기 전용 권한, 예약 실행 없음.
